# ТЗ: платформа для репетиторов и онлайн-школ иностранных языков

> Рабочее название: **LinguaRoom** (заменить позже).
> Версия документа: 1.0, ноябрь 2026.

---

## 1. Суть продукта

Веб-платформа, где репетитор иностранного языка:
- ведёт учеников (индивидуально и в группах);
- проводит живые уроки по готовым или своим материалам — урок открывается одновременно у учителя и ученика, учитель видит ответы ученика в реальном времени;
- задаёт домашние задания с автопроверкой и видит, как ученик их выполнил;
- даёт ученику личный словарь и тренажёр слов.

**Позиционирование:** простая, стабильная и понятная альтернатива ProgressMe / Edvibe. Главные ценности — **надёжность** (ничего не ломается во время урока), **простота** (минимум лишних кнопок, понятно с первого раза) и **готовый контент** (учебники по уровням из коробки).

**Первые пользователи:** автор проекта (репетитор) и его ученики. Потом — открытие для других репетиторов по всему миру, позже — онлайн-школы.

---

## 2. Роли

| Роль | Что может |
|---|---|
| **Учитель** | Создаёт классы, приглашает учеников, создаёт и редактирует уроки и курсы, проводит живые уроки, задаёт и смотрит домашку, комментирует, ведёт расписание, видит статистику, пишет в чат |
| **Ученик** | Заходит в свои классы, проходит уроки вместе с учителем, делает домашку, видит свои ошибки и комментарии, ведёт словарь, занимается в тренажёре, пишет в чат |
| **Админ платформы** (автор проекта) | Создаёт и публикует «официальные» учебники в библиотеке платформы; в первой версии это просто учитель с флагом `is_admin` |

Позже (не в MVP): роль «администратор школы» с несколькими учителями.

## 3. Общие требования

- **Языки интерфейса:** русский, английский, казахский. Все тексты интерфейса — только через систему переводов (никакого текста прямо в коде). Язык выбирается в профиле, по умолчанию — язык браузера.
- **Преподаваемые языки:** любые. Архитектура не привязана к английскому. Первые готовые курсы — английский.
- **Устройства:** адаптивная вёрстка. Учитель в основном работает с компьютера; ученик — с компьютера, планшета и телефона (домашка и тренажёр особенно должны быть удобны с телефона).
- **Дизайн:** дружелюбный, но спокойный и чистый. Крупные понятные элементы, мягкие цвета, скруглённые карточки. Минимум кнопок на экране — второстепенные действия прячутся в меню «…». Каждый экран должен быть понятен человеку, который видит платформу впервые.
- **Надёжность:** живой урок не должен «падать». При потере соединения — автоматическое переподключение и восстановление состояния без перезагрузки страницы; понятный индикатор «нет связи».
- **Автосохранение:** всё, что вводит учитель в конструкторе и ученик в ответах, сохраняется автоматически.

## 4. Структура контента

```
Курс (учебник), напр. «Английский A2»
 └── Модуль 1 «Знакомство»
      ├── Урок 1.1
      │    ├── Секция «Warm-up»
      │    │    ├── Упражнение 1 (картинка + вопросы)
      │    │    └── Упражнение 2 (...)
      │    ├── Секция «Listening»
      │    └── ...
      ├── Урок 1.2
      └── Тест по модулю 1
 └── Модуль 2 ...
```

- **Курс:** название, преподаваемый язык, уровень (A1–C2 или свободный), описание, обложка. Курс — либо из библиотеки платформы, либо личный курс учителя.
- **Модуль:** название, порядок, набор уроков и (необязательно) промежуточный тест.
- **Урок:** название, порядок, список секций, список слов урока (необязательно).
- **Секция:** свободное название, которое задаёт учитель. При создании предлагаются шаблоны: Warm-up, Vocabulary, Grammar, Listening, Reading, Speaking, Writing, Homework.
- **Упражнение (блок):** нумерация автоматически по секции (1.1, 1.2…), тип, заголовок/инструкция, содержимое, правильные ответы.
- **Тест по модулю:** урок с флагом «тест» — у ученика показывается результат в процентах, результат попадает в статистику.

Курс из библиотеки **не редактируется** учителем напрямую: учитель может сделать **копию** и править её. Любой урок и курс можно дублировать.

## 5. Типы блоков и упражнений

### Блоки-материалы (без проверки)
1. **Текст** — форматированный текст (заголовки, жирный, списки, выделение цветом).
2. **Картинка** — одна или несколько, с подписью.
3. **Видео** — загрузка файла или ссылка YouTube/Vimeo.
4. **Аудио** — загрузка файла, плеер с перемоткой и скоростью воспроизведения (0.75x / 1x / 1.25x).
5. **Файл** — PDF/документ для просмотра или скачивания.

### Упражнения с автопроверкой
6. **Пропуски с вводом** — текст, в котором учитель отмечает слова-пропуски; можно задать несколько правильных вариантов; настройка «учитывать регистр» (по умолчанию нет).
7. **Пропуски с выпадающим списком** — у каждого пропуска свои варианты.
8. **Пропуски с перетаскиванием** — слова из «банка слов» перетаскиваются в пропуски.
9. **Выбор ответа** — один правильный / несколько правильных; варианты могут быть текстом или картинками.
10. **Верно / неверно.**
11. **Сопоставление** — пары «слово–слово», «картинка–слово», «аудио–слово».
12. **Порядок** — собрать предложение из слов или расставить фразы/абзацы по порядку.
13. **Распределение по группам** — перетащить слова в колонки (напр. «Countable / Uncountable»).

### Упражнения с ручной проверкой
14. **Открытый ответ** — короткий ответ или эссе; настройка минимального количества слов; счётчик слов.
15. **Голосовой ответ** — ученик записывает аудио прямо в браузере, может переслушать и перезаписать.

К любому упражнению можно прикрепить медиа сверху (например, картинка в Warm-up + вопросы под ней, или аудио + тест по нему).

**Важно по безопасности:** правильные ответы **никогда не отправляются в браузер ученика** до того, как он ответил. Проверка ответа происходит на сервере.

## 6. Конструктор уроков (для учителя)

Главный экран, на котором учитель проводит больше всего времени — он должен быть максимально простым.

- Слева — список секций урока (перетаскивание для смены порядка), кнопка «+ Секция».
- Справа — содержимое секции: список упражнений, кнопка «+ Упражнение».
- «+ Упражнение» открывает окно с типами упражнений: иконка + название + короткое описание, сгруппированы («Материалы», «С автопроверкой», «С ручной проверкой»).
- Редактирование упражнения — прямо на месте, в режиме «как увидит ученик», без отдельных сложных форм. Пример для пропусков: учитель пишет текст и выделяет слово → кнопка «Сделать пропуском».
- Кнопка **«Предпросмотр как ученик»** — можно сразу пройти упражнение.
- Действия с упражнением в меню «…»: дублировать, переместить в другую секцию, удалить.
- Загрузка медиа перетаскиванием файла.
- Автосохранение + индикатор «Сохранено».

## 7. Классы и приглашения

- **Класс** — пространство учителя с одним учеником (индивидуальный) или несколькими (группа).
- Учитель создаёт класс → получает **ссылку-приглашение** → ученик переходит по ссылке, регистрируется (email + пароль или вход через Google) и сразу попадает в класс.
- Ссылку можно отключить/перевыпустить.
- К классу привязываются один или несколько курсов. В классе видно: курсы → модули → уроки, с отметками «пройден / в процессе / не начат».
- В классе вкладки: **Уроки**, **Домашка**, **Словарь** (для ученика), **Чат**, **Статистика** (для учителя).

## 8. Живой урок

Сценарий: учитель и ученик созваниваются в Zoom/Meet (ссылка на звонок хранится в классе и открывается одной кнопкой), учитель открывает урок на платформе.

- Учитель нажимает **«Начать урок»** → у всех учеников класса, которые онлайн, урок **автоматически открывается**. Кто зайдёт позже — увидит баннер «Идёт урок — присоединиться».
- Дальше каждый листает урок **сам** (навигация не синхронизируется).
- **Ответы видны вживую:** учитель видит, что ученик вводит/выбирает, в реальном времени, ещё до проверки. В группе — переключатель между учениками и общий обзор «кто сколько сделал».
- **Указка и подсветка:** учитель может показать курсором место на странице и выделить фрагмент текста — ученик видит указку и подсветку, если находится в той же секции. Кнопка **«Показать ученику»** — прокручивает экран ученика к месту, где находится учитель (разовое действие, а не постоянная синхронизация).
- **Интерактивная доска:** в уроке можно открыть общую доску (рисование, текст, фигуры), которая видна всем участникам урока. Доску можно добавить и как блок внутри урока.
- Учитель может **сбросить ответы** упражнения, чтобы сделать его ещё раз, и **показать правильные ответы**.
- **Завершить урок** — урок отмечается как пройденный, ответы сохраняются.
- Индикатор присутствия: учитель видит, кто из учеников онлайн и в какой секции находится.

## 9. Домашние задания

- Учитель задаёт домашку из урока: весь урок, отдельные секции или отдельные упражнения. Можно указать срок сдачи (необязательно).
- У ученика вкладка **«Домашка»**: список заданий со статусами — *новое, в процессе, сдано, просрочено*.
- Ученик выполняет задания; **ответ проверяется сразу** при вводе/выборе: правильный — зелёный, неправильный — красный. Ученик может попробовать ещё раз; учитель видит и первую попытку, и количество попыток.
- Открытые и голосовые ответы помечаются «ждёт проверки учителем».
- Кнопка **«Сдать»** — у учителя домашка появляется как сданная.
- Учитель открывает домашку и видит ответы ученика с ошибками. К любому ответу учитель может оставить **комментарий** (правильный вариант, объяснение) — ученик видит комментарий рядом с упражнением. Основной разбор — устно на уроке.
- У учителя общий список «Домашка» по всем классам: что сдано и ждёт просмотра.
- Уведомления (в первой версии — внутри платформы, значок с числом): ученику — о новой домашке и комментарии; учителю — о сданной домашке. Email/Telegram — позже.

## 10. Словарь и тренажёр

### Словарь
- У каждого ученика — личный словарь (общий для всех классов, с фильтром по курсу/уроку).
- Слова добавляются:
  - **учителем во время урока** — кнопка «+ в словарь ученика» (в группе — всем или выбранным ученикам);
  - **учеником самостоятельно** — вручную или выделив слово в тексте урока → «Добавить в словарь».
- Карточка слова: слово/фраза, перевод, транскрипция, озвучка, пример, картинка (необязательно), откуда добавлено.
- **Транскрипция и озвучка:** в MVP — озвучка через встроенный синтез речи браузера, для английского — транскрипция и аудио из бесплатного словарного API (напр. dictionaryapi.dev), если доступно. **Автоперевод** — в этапе ИИ (см. раздел 13); до этого перевод вводится вручную.

### Тренажёр
- Режимы:
  1. **Карточки** с интервальным повторением (алгоритм FSRS): «Не помню / Трудно / Помню / Легко»;
  2. **Выбор перевода** из 4 вариантов;
  3. **Написание слова** по переводу или на слух.
- Главный экран тренажёра: «На сегодня к повторению: N слов» → кнопка «Начать».
- Статус каждого слова: новое / изучается / выучено.
- Учитель видит прогресс ученика по словарю.

## 11. Расписание, чат, статистика

- **Расписание:** учитель создаёт занятия (класс, дата, время, повторение еженедельно), календарь неделя/месяц; ученик видит свои ближайшие занятия. Время показывается в часовом поясе пользователя. Ссылка «Начать урок» прямо из события.
- **Чат:** в каждом классе, текст + файлы/картинки, отметка о прочтении.
- **Статистика (для учителя):** по ученику — пройденные уроки, % правильных в домашках и тестах, результаты тестов по модулям, сданные вовремя/с опозданием, прогресс словаря. Простые графики, без перегруза.

---

## 12. Библиотека готовых учебников

- Раздел «Библиотека»: курсы платформы, фильтр по языку и уровню.
- Курс можно открыть, посмотреть, назначить классу или скопировать к себе для редактирования.
- Контент — **оригинальный**, создаётся автором проекта (с помощью ИИ). Чужие учебники не загружаются.
- Позже: учителя могут публиковать свои курсы в общую библиотеку.

## 13. Этапы разработки

Каждый этап заканчивается рабочей версией, которую можно проверить руками.

### Этап 0 — Основа
- Проект Next.js + TypeScript + Tailwind + shadcn/ui, Supabase, деплой на Vercel.
- Регистрация и вход (email + пароль, Google), роли учитель/ученик, профиль.
- Мультиязычность (ru / en / kk) с переключателем.
- Базовый макет: боковое меню учителя и ученика.
- ✅ Готово, когда: можно зарегистрироваться учителем, переключить язык, деплой работает.

### Этап 1 — Курсы и конструктор
- Курсы → модули → уроки → секции → упражнения: создание, редактирование, порядок, дублирование.
- Все блоки-материалы и упражнения с автопроверкой (типы 1–13), загрузка медиа.
- Предпросмотр как ученик, серверная проверка ответов.
- ✅ Готово, когда: учитель может собрать урок из 3+ секций с разными типами упражнений и пройти его в предпросмотре.

### Этап 2 — Классы и живой урок
- Классы (индивидуальные и группы), ссылки-приглашения, регистрация ученика по ссылке.
- Привязка курсов к классу, статусы уроков.
- Живой урок: автооткрытие у ученика, ответы вживую, присутствие, сброс/показ ответов, «Показать ученику», указка и подсветка.
- Ссылка на Zoom/Meet в классе.
- ✅ Готово, когда: в двух браузерах (учитель + ученик) урок открывается у ученика сам, учитель видит ответы ученика без задержки, после обрыва интернета всё восстанавливается.

### Этап 3 — Домашка
- Упражнения с ручной проверкой (открытый ответ, голос).
- Назначение домашки, статусы, сроки, мгновенная проверка, попытки, сдача, комментарии, внутренние уведомления.
- ✅ Готово, когда: учитель задал домашку → ученик сделал с телефона → учитель увидел ответы, ошибки и оставил комментарий → ученик его увидел.

### Этап 4 — Словарь и тренажёр
- Словарь (добавление учителем и учеником, выделение слова в тексте), озвучка, транскрипция.
- Тренажёр: три режима, FSRS.
- ✅ Готово, когда: слово, добавленное учителем на уроке, появилось у ученика и пришло на повторение в тренажёре.

### Этап 5 — Тесты, статистика, расписание, чат
- Тесты по модулям, статистика, расписание, чат.

### Этап 6 — Интерактивная доска
- Общая доска на уроке (на основе Excalidraw или аналога с подходящей лицензией).

### Этап 7 — ИИ-функции и контент
- Импорт PDF/Word → черновик урока с секциями и упражнениями (через Claude API), учитель проверяет и правит.
- Автоперевод слов, генерация упражнений по теме/тексту.
- Наполнение библиотеки: первый курс «Английский A2».

### Позже (вне текущего плана)
Встроенная видеосвязь (LiveKit), оплаты и тарифы, аккаунты школ, уведомления в email/Telegram, мобильное приложение (Expo), публичная библиотека курсов учителей, хостинг данных с учётом законов о персональных данных (напр. РФ — 152-ФЗ).

## 14. Техническая основа

| Часть | Технология |
|---|---|
| Фронтенд + сервер | Next.js (App Router), TypeScript |
| UI | Tailwind CSS, shadcn/ui, иконки lucide |
| База данных, вход, файлы, real-time | Supabase (PostgreSQL, Auth, Storage, Realtime) |
| Переводы интерфейса | next-intl |
| Перетаскивание | dnd-kit |
| Текстовый редактор | Tiptap |
| Интервальное повторение | ts-fsrs |
| Хостинг | Vercel |
| Тесты | Vitest (логика), Playwright (ключевые сценарии) |

### Основные таблицы (черновик)
- `profiles` — пользователь, роль, имя, язык интерфейса, часовой пояс, `is_admin`
- `courses`, `modules`, `lessons`, `sections`, `exercises` (тип, `content` jsonb, `answer_key` jsonb — недоступен ученику)
- `classes` (тип: individual / group, ссылка на звонок), `class_members`, `class_invites`, `class_courses`
- `lesson_sessions` — живые уроки (класс, урок, начат/завершён)
- `answers` — ответ ученика на упражнение (контекст: урок / домашка / тест, ответ jsonb, верно/неверно, попытки, время)
- `homework`, `homework_items`, `homework_submissions`
- `comments` — комментарии учителя к ответам
- `vocabulary` + поля состояния FSRS, `vocabulary_reviews`
- `schedule_events`, `messages`, `notifications`

**Каждая таблица защищена RLS-политиками:** ученик видит только свои ответы и классы, учитель — только своих учеников и свои материалы.
